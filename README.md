# The-Computational-Model-of-Deja-Reve
An information-theoretic and algorithmic approach to human consciousness glitches. This project models déjà rêvé (the feeling that a present waking moment was already experienced in a dream) not as a supernatural phenomenon, but as a sub-string pattern matching event operating under hard biological processing constraints.


Core Postulates

1. The REM Infinite String: During REM sleep, the hyper-associative firing of the hippocampus and amygdala generates an incredibly long, continuous string of neural firing patterns (represented mathematically as a high-dimensional vector or a long decimal sequence like π).
2. The Waking Sub-String Query: Waking reality is processed as shorter, highly structured neural strings.
3. Stochastic Alignment: Due to the sheer volume of chaotic dream data generated over a lifetime, there is a non-zero statistical probability that a waking string will perfectly match a sub-string segment buried deep within the forgotten dream database.
4. The Biological Bottleneck: The brain acts as a reducing valve (managed by the thalamus and prefrontal cortex) to filter out background noise. Déjà rêvé occurs on the rare occasion a precise "bulls-eye" alignment breaks through this filter. Because the matching data resides in a chaotic dream network, the brain fires a familiarity signal without matching contextual metadata, creating an uncanny, unorthodox sensation.


# 💻 Simulation & Implementation

The repository contains a computational proof-of-concept simulation written in Python. It simulates the generation of a noisy, high-frequency REM dream stream, injects a hidden alignment sequence, and uses a rolling Mean Squared Error (MSE) search algorithm to locate the sub-string.
